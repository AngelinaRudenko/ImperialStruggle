2. Unzip it and run .exe

Renderer
- Forward+ это «всё включено». Он нужен, когда важны красивое 3D, сложное освещение и тени, а также продвинутые постэффекты.
- Mobile это компромисс для мобильных устройств, где нужны Vulkan и экономия ресурсов.
- Compatibility это самый «лёгкий» и «всеядный» вариант. Он запускается практически везде, но часть современных эффектов в нём недоступна или ограничена.

Для простой 2D-игры с перетаскиванием объектов мышью я бы выбрал Compatibility.
- Supports desktop, mobile + web platforms
- Least advances 3D graphics
- Intended for low-end/older devices
- Uses OpenGL 3 backend
- Fastest rendering of simple scenes
- Вам не нужны тяжёлые эффекты, ради которых существует Forward+. Для спрайтов, UI, перетаскивания и простых анимаций хватает любого рендерера.
- Игра запустится на самом широком круге компьютеров, в том числе на старых ноутбуках и на встроенной графике без нормального Vulkan.
- Проект легче, а запуск из редактора быстрее.
- Базовые 2D-возможности (спрайты, тайлмапы, 2D-освещение, шейдеры) в нём работают.
